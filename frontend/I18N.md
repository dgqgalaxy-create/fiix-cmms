# Traducción de la interfaz (i18n)

## Cómo funciona

- **Idioma del sistema:** `SystemSettings.language` (`es` | `en`).
  Se cambia en **Configuración → Idioma** o con `PATCH /api/settings { language }`.
- **Textos nuevos:** usar `const { t } = useI18n()` y `t('clave')`.
  El diccionario está en `src/i18n/translations.ts` (claves nombradas).
- **Textos existentes (retrofit):** `src/i18n/en-app*.ts` traduce por **texto en
  español**. La clave es el propio texto original, así que migrar una cadena es
  agregar una línea al diccionario, sin tocar componentes.
- **Aplicación al DOM:** cuando el idioma es `en`, `src/i18n/domTranslate.ts`
  recorre la página y sustituye los textos que existen en el diccionario
  (incluye `placeholder`, `title`, `aria-label` y `alt`). Recuerda el original
  para poder volver a español sin recargar. Es una capa temporal.

## Herramientas

```bash
# Cobertura por archivo (cadenas traducidas / visibles)
node scripts/i18n-missing.cjs

# Detalle de lo que falta en archivos concretos
node scripts/i18n-missing.cjs pages/StatsPage.tsx components/ItemModal.tsx

# Volcar todas las cadenas únicas extraídas
node scripts/i18n-extract.cjs --json
```

## Reglas de estilo

- Inglés técnico de mantenimiento: *work order*, *spare part*, *downtime*,
  *preventive*, *corrective*, *SLA*, *backlog*.
- No traducir datos del usuario (nombres de activos, zonas, notas).
- Mantener las mismas mayúsculas/minúsculas de la UI (títulos en mayúscula
  inicial, etiquetas cortas).
