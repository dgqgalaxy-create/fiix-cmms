# GTZ CMMS v1.69.0

Fecha: 20 de octubre de 2026.

## Mejoras

- Nuevo panel de desempeño individual para técnicos y gestionadores, con indicadores del periodo, gráficas mensuales, historial de OT, filtros combinables por zona (selección múltiple), activo, tipo y estado, y orden ascendente o descendente por tiempo de respuesta o reparación.
- El historial permite abrir el detalle completo de una OT en una ventana superpuesta y generar un PDF visual con métricas, gráficas, alcance y órdenes filtradas/ordenadas.
- Nuevo ranking entre técnicos y gestionadores activos por OT finalizadas en el periodo. Excluye administradores; las órdenes asignadas a más de una persona se cuentan para cada asignado. El podio distingue los tres primeros lugares por color y número, sin etiquetas de metales.
- Personal: las tarjetas de técnicos y gestionadores incluyen «Ver desempeño». El regreso conserva el origen y, si se abrió desde Personal, restaura pestaña, búsqueda, vista y filtro de inactivos.
- Inicio: el contador «Personal en turno ahora» pasa de Personal a la parte derecha de Sala de Control. Al abrirlo, lista técnicos y gestionadores activos cuyo turno está vigente, con fecha y hora de planta.
- Sala de Control: «Urgentes abiertas» y «Sin asignar» abren un listado modal de todas las OT abiertas que coincide con el conteo. Seleccionar una OT abre su detalle encima del listado; cerrar el detalle devuelve a la lista.

## Cambios de datos y despliegue

No requiere migraciones de base de datos ni variables de entorno nuevas. El backend amplía el cálculo del ranking y los filtros de consulta existentes; el resto de los cambios es de interfaz y documentación.

Un push a `main` activa el despliegue del runner self-hosted mediante GitHub Actions (`ci-typecheck.sh` y `update.sh`). Revisar que el flujo termine correctamente antes de considerar producción actualizada. La versión estable de restauración continúa siendo `v1.66.0`.
